# 动力站管道轻量化模型管理平台

本项目以 `tileset.json` 为入口，使用 Cesium 直接请求其引用的 `.b3dm` 分块；浏览器会依视距自动选择 LOD 0/1/2。模型数据位于 `public/models/`，其文件名和相对路径不可更改。

`structure.json`、`全部对象属性.csv` 与 b3dm 批量表会在构建时整理为 `public/models/model-index.json`：该索引把结构树节点、构件 `componentId`、空间包围盒和 EP3D 属性关联起来。

## 本地一键打开

在 Windows 文件资源管理器中双击 `启动动力站模型平台.cmd`。若已安装 Node.js，入口会启动带“焊接日期”同步接口的服务；否则自动退回只读静态模型服务。服务就绪后会自动在默认浏览器打开平台。保持命令窗口开启即可持续提供服务，按 `Ctrl+C` 或关闭窗口即可停止服务。如果 4173 已被占用，会自动尝试 4174–4183。

## 启动

```powershell
pnpm install
pnpm run build
node server.mjs
```

服务默认监听所有网卡的 4173 端口。部署主机访问 `http://localhost:4173`，局域网其他设备访问 `http://<部署主机IP>:4173`。如端口被占用，可执行 `$env:PORT=8080; node server.mjs`。

若 Windows 防火墙提示，请允许 Node.js 的“专用网络”访问；局域网终端才能访问服务。

## 性能设计

- 3D Tiles 按视距动态加载，初始优先低精度 LOD；
- 关闭地形、影像、天空和在线服务，避免额外网络请求；
- 分块模型和 JSON 在服务端开启 24 小时缓存；
- 固定 1 倍渲染分辨率，右侧滑块可在“精细 / 均衡 / 流畅”间调节屏幕空间误差。

## 构件交互

- 点击结构树条目：对应 b3dm 构件变为黄色，相机旋转并飞至构件的包围盒中心；后续旋转以该中心为原点，其他构件自动淡化；
- 点击三维模型：由 b3dm 的 `componentId` 反查结构树并自动滚动、选中对应条目；
- 右侧“EP3D PROPERTIES”展示选中构件的属性，例如焊点编号、元件编号、材料编码、规格及管线号；
- 搜索框可按结构名、构件名、管线或属性中的编号快速筛选。

## 焊接日期与云端同步

- 可上传、共享编辑的工作副本位于 `data/动力站焊接数据库-云端同步.xlsx`。平台以 `管线号 + 焊点编号`（例如 `CWR-08001-125-QHA#1`）对应模型焊缝的 EP3D 属性。
- 空白的“焊接日期”会在平台中显示为稳定的虚拟日期，并标注“虚拟值（待云端填写）”；云端数据库填入真实日期后，页面会显示“云端焊接数据库”。
- 将该副本上传至 WPS 云文档并授予协作者编辑权限后，使用 WPS 的本地同步文件作为服务数据源。启动前在 PowerShell 设置其路径：

```powershell
$env:WELD_DB_PATH = 'C:\WPS云文档\动力站焊接数据库-云端同步.xlsx'
node server.mjs
```

每次刷新浏览器，`/api/weld-status` 都会按文件修改时间重新读取该工作簿，因此 WPS 同步到本机后的日期修改会在刷新后生效。没有配置该环境变量时，服务读取项目内的工作副本。
